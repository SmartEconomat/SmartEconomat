# Documentacion SmartEconomat

Indice canonico y mantenible del proyecto. Esta carpeta queda organizada para onboarding, mantenimiento tecnico y seguimiento de negocio.

## Documentos canonicos

- `architecture.md` - arquitectura real por capas y componentes.
- `patrones-arquitectura.md` - patrones de diseno usados en backend y frontend (factory, adapter, guards, context, etc.).
- `business-rules.md` - logica operativa y reglas de negocio vigentes.
- `installation.md` - puesta en marcha (Docker y local).
- `configuration.md` - configuracion de runtime, puertos y servicios.
- `environment-variables.md` - inventario consolidado de variables de entorno.
- `development.md` - flujo de desarrollo, scripts y convenciones.
- `deployment.md` - despliegue real (compose prod + GitHub Actions).
- `testing.md` - estrategia de pruebas y comandos reales.
- `troubleshooting.md` - fallos frecuentes y resolucion.
- `faq.md` - preguntas recurrentes.
- `changelog.md` - cambios documentales.
- `documentation-audit-report.md` - auditoria, inconsistencias y riesgos.

## Documentacion complementaria

La documentacion historica, detallada por modulo o academica sigue disponible en subcarpetas (`modules/`, `frontend/`, `installer/`, `archive/`), pero los archivos anteriores son la referencia principal.

- Fuente de verdad: comportamiento real del codigo.
- No duplicar informacion entre documentos canonicos.
